🔒 سياسة الخصوصية | Privacy Policy

آخر تحديث | Last Updated: 2024

1. البيانات التي نجمعها | Data We Collect

يقوم البوت بجمع وتخزين البيانات التالية فقط:
The bot collects and stores only the following data:

  • معرّف المستخدم Discord ID — لحفظ الأدوار وإعادتها عند العودة للسيرفر
    Discord User ID — to save and restore roles when rejoining the server
  • قائمة الأدوار المخصصة للعضو | Member's assigned role IDs

2. كيف نستخدم البيانات | How We Use Data

البيانات المجمعة تُستخدم حصرياً لأغراض تشغيل البوت داخل سيرفر قرية ماهركم البسيطة، مثل إعادة الأدوار للأعضاء العائدين.
Collected data is used exclusively for bot operations within The Village server, such as restoring roles for returning members.

3. مشاركة البيانات | Data Sharing

لا نشارك أي بيانات مع أطراف ثالثة.
We do not share any data with third parties.

4. حذف البيانات | Data Deletion

يمكنك طلب حذف بياناتك في أي وقت عبر التواصل مع مسؤولي السيرفر على Discord.
You can request deletion of your data at any time by contacting the server admins on Discord.

5. الأمان | Security

نحرص على حماية بياناتك، غير أنه لا يمكن ضمان الأمان المطلق لأي نظام إلكتروني.
We strive to protect your data, but cannot guarantee absolute security of any electronic system.

6. التواصل | Contact

للاستفسارات المتعلقة بالخصوصية، تواصل معنا عبر سيرفر Discord الرسمي.
For privacy-related inquiries, contact us through the official Discord server.
